# Requirements

## How to use this document

Use stable IDs. A requirement is accepted only when the accountable human approves it in a PR or Issue comment. Link every delivery Issue to one or more IDs.

An approved change receives a new or revised ID, states its release impact, and is accepted by the accountable human. The orchestrator then updates linked Issues and the Project.
