# Backend Development

1. Confirm expected request/response, actor permissions, validation, errors, and data invariants in the contract.
2. Implement server-side authorization and validation, predictable errors, logging/observability where relevant, and tests.
3. Coordinate schema changes with the database agent; document migration and rollback plans.
4. Keep changes within the Issue. Document API changes before frontend handoff.
5. Open a linked draft PR with test output and risks.
