# Code Review

1. Read the linked Issue, requirements, diff, tests, contracts, and PR evidence.
2. Prioritize incorrect behaviour, authorization, data loss, race conditions, compatibility, privacy, accessibility, performance, and missing tests.
3. Write specific findings with severity and a failure scenario; avoid aesthetic-only blocking comments.
4. Verify documentation and migration/rollback implications.
5. Approve or request changes. Human branch policy controls merge.
