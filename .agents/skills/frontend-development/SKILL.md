# Frontend Development

1. Read Issue, requirements, API contract, existing UI patterns, and test plan.
2. Implement semantic structure and every specified loading/empty/error/validation state.
3. Verify keyboard navigation, focus management, readable errors, responsive layout, and appropriate automated tests.
4. Do not alter API semantics or authorization policy without an approved contract decision.
5. Open a linked draft PR with visual and test evidence for QA.
